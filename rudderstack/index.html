Why this
session

RudderStack is built for a world where humans and autonomous agents work together to collect, unify, and activate customer data. Infrastructure as code and an MCP unlock agentic workflows — so data and engineering teams build, govern, and manage pipelines through natural language, with safety built in.

In this session we'll show what that looks like on a real stack: a tracking agent built with Cursor that cut time-to-insight from six weeks to a few days for one data team — the same story RudderStack customer QJ Flores (Staff Data Engineer, VSCO) tells about their own pipeline. We'll walk the same path live, from raw event to governed customer 360.

Agentic, from end to end

The same COLLECT → UNIFY → ACTIVATE → GOVERN lifecycle shown on rudderstack.com — walked through live.

✦

Collect

Capture clean data with intelligent tracking — standardized events from every channel, reshaped in flight to clean, enrich, and mask PII.

✦

Unify

Resolve identifiers into an identity graph and build a customer 360 with pre-computed features like LTV — no SQL required.

✦

Activate

Stream governed data to 200+ destinations, or self-serve audiences with an AI-native chat experience.

✦

Govern

Enforce data quality and compliance before data ships downstream, so every team and every agent gets activation-ready data.
